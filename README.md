# 国富论本地阅读器

Windows 本地阅读器，支持双页阅读、翻页、搜索、字号和夜间模式。书籍正文内嵌在阅读器页面中。

## 网页版

网址：<https://celestialmoon97520.github.io/ReadLongTime/>。进度、字号和夜间模式保存在当前浏览器；清除网站数据、更换浏览器或设备后不会自动同步。使用“进度迁移”可以从本地版导出并导入，也可以在不同设备间手动迁移。

## 本地版使用

1. 安装 Python 3，下载并解压项目。
2. 双击 `启动国富论阅读器.vbs`，程序会启动仅监听本机的服务，并用默认浏览器打开阅读器。也可以运行 `启动国富论阅读器.cmd`。
3. 阅读时进度和设置自动保存到本机 `storage/personal.sqlite3`，这个文件不会提交到 GitHub。仓库不会跨设备自动同步进度；更换设备可通过页面的“进度迁移”功能导出并导入迁移码。
4. 关闭阅读页面后服务会在最后一个页面断开并经过缓冲后自动退出；也可使用页面中的“关闭服务”。

网络异常、浏览器崩溃、多页面写入冲突或存储不可用时，最后一次保存不保证成功。遇到页面提示时请先导出迁移码。
